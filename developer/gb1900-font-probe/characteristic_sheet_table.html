Every OS category as its own row with its own exemplar. Source: OS 1897 “Examples for the Characters…” (NLS view/128076792) + c.1923 Plate IV (NLS view/128076894), CC-BY NLS, via IIIF. The classifier predicts a typographic STYLE (the coloured pill = the 5 visually-separable classes); a later fusion maps (style × text × size × date-regime) → feature-type. Please tick each row or note a correction.
